### 3f — 1枚に戻って、文字と座標に

- 語り: 風土記では、まずそれぞれの情報を、OCR やテキストの読み出しで、テキストと座標に変換しました。
- 画: 3a と同じ決算書の頁が1枚、真ん中に置かれた状態から入る（3e の最後の画とはつなげなくてよい）→ 頁の上の文字・金額に座標の枠が順に付く → 枠から「テキスト＋座標」のラベルが横に引き出される。対象:
  - 議員報酬及び期末手当等 / 499,424,236 / （1）報酬 286,477,996 / （2）期末手当 138,121,200 / （3）共済費 74,825,040
- 座標は**実際の値**を使う（`[x0, y0, x1, y1]` のプレースホルダではなく）。原典: `/Users/yuito_watanabe/orca/workspaces/fudoki/fiscal-jev-coverage-2/pipeline/.cache/objects/fiscal/source-selection/132012/2025/settlement-1.pdf` 物理 p.148。`pdftotext -f 148 -l 148 -bbox <pdf> -` で語ごとの枠（pt）が取れる。表示は小数1桁か整数で短く。枠の位置は `pdf-3a.png` の切り抜き範囲に合わせて換算して頁の上に重ねる（切り抜きの原点は `pdf-3a.png` と原典を描画して突き合わせて求める）。

### 3g — 座標から木構造へ

- 語り: これらの座標情報を木構造に変換し、管理するようにしました。
- 画: 3f の枠（ラベル）が頁から剥がれて移動し、上から款→項→目→事業→内訳のツリーに組み上がる。頁はフェードアウト。
  - 款 議会費 754,711,008
  - 項 議会費
  - 目 議会費
  - 事業 議員報酬及び期末手当等 499,424,236 ／ 事業 議会の運営 38,381,754
  - 内訳（議員報酬及び期末手当等の下）: 報酬 286,477,996 ／ 期末手当 138,121,200 ／ 共済費 74,825,040
- 款の下には他の事業もあるが、2事業だけ見せる。金額は p.148 の印字どおり（確認済み: 上の数字はすべて text layer にある）。

### 3h — 1つの目から、自治体ごとに違う枝が生える

- 語り: これにより、自治体ごとの差分を抑えた、柔軟なフォーマットへの対応が可能です。
- 画: PDF は出さない。3g のツリーが引いて（または縮んで）「目」のノード1つに収束 → 中央上に目のノード → そこから自治体A→B→C→D の順に、つながり方の違う枝が1本ずつ生えて伸びる。各枝の下に注記:
  - 自治体A: 目 → 節
  - 自治体B: 目 → 事業 → 節
  - 自治体C: 目 → 節・説明・財源（目の直下に3種が並ぶ）
  - 自治体D: 目 → 事業 → 内訳 → 細目
- ノードの色はノードの種類で分ける（節＝青系、事業＝赤枠、説明＝黄系、財源＝紫系、内訳・細目＝灰枠）。どれも同じ1つの目から派生した同じ木として持てることが伝わればよい。

### 3i — 子の合計 ＝ 親の金額 で検算

- 語り: それぞれのノードの金額の合計と、親ノードの金額が等しいことを確かめることで、データの正しさを担保しています。
- 画: 3g のツリーに戻る（3h の最後から 3g のツリーへ組み替える動きを 3i の冒頭に入れてよい。ただし 3i の最初のフレームは 3h の最後のフレームと同じ）。内訳3つの金額が枝を伝って事業へ足し上がり、「286,477,996 ＋ 138,121,200 ＋ 74,825,040 ＝ 499,424,236」で一致して✓（青）。そのあとツリー全体のノードに✓が波のように広がって静止。
- 画面に出す式・数字は上のとおり（作った数字を出さない）。
